# 하드웨어 구성도 v0.1

**작성일** 2026-08-27 · 실기 사진 판독 + `src/*/config` 티칭값 기준

Doosan M0609 협동로봇 한 대가 툴 5종을 갈아 끼우며 인조 네일팁 한 개를 시술하는
작업 셀의 물리 구성이다. 전용 지그를 제작하지 않고 레고 브릭으로 툴 랙과 작업물
지그를 구성했다.

---

## 1. 작업대 평면도

![작업대 평면도](diagrams/nailbot_cell_layout.png)

위에서 내려다본 배치다. 로봇은 왼쪽에서 팔을 뻗어 들어오고, 툴 네 자리가 작업물을
둘러싸고 반원으로 놓여 있다. 붓만 **작업대 바깥 구멍**에 세워 두고, 작업물인
네일팁은 지그로 **툴 랙보다 한참 높게** 올려 두었다. 도면 속 번호는 공정 순서다.

| 번호 | 툴 | 공정 |
|---|---|---|
| 1 | 네일 파일 (`sander`) | 연마 |
| 2 | 붓 (`brush`) | 분진 제거 |
| 3 | 젤 네일 (`coater`) | 도포 |
| 4 | UV 램프 (`uv`) | 경화 |
| 5 | 핀셋 (`tweezers`) | 스톤 부착 |

물체의 상대 위치는 `nail_skill/config/targets.yaml`의 실측 티칭 좌표를 그대로
따랐다.

## 2. 장비 연결 구성

![장비 연결 구성도](diagrams/nailbot_hardware_stack.png)

키오스크용 별도 모니터는 없고, ROS2 노드·rosbridge·FastAPI·PostgreSQL·브라우저가
**PC 한 대**에서 전부 돈다. E-Stop은 별도 버튼이 아니라 **티치펜던트에 내장**돼
있다. UV 램프는 USB 전원이 상시 연결돼 있어 소프트웨어로 끄고 켤 수 없다 —
그래서 웹에 "UV 상시 ON" 경고 배너를 상시 표시한다.

## 3. 구성품

| 구성품 | ROS 키 | 형태 · 보관 | 특이사항 |
|---|---|---|---|
| 네일 파일 | `sander` | 작업대 위 브래킷에 눕혀 보관 | 손톱면을 곡선으로 연마 |
| 분진 제거용 붓 | `brush` | **작업대 바깥 구멍**에 꽂아 세워 보관 | 경유점 없이 작업 위치로 직행 (2026-08-26 변경) |
| 젤 네일 (뚜껑 = 붓) | `coater` | 작업대 위 함에 세워 보관 | `unscrew: true` — 돌려 열고, 반납 시 돌려 잠금. 붓의 젤 여분은 병 입구에 훑어냄 |
| UV LED 램프 | `uv` | 작업대 위 받침에 눕혀 보관, USB 케이블 상시 연결 | 상시 ON · 소프트웨어 제어 없음. 경유점 없이 직행 |
| 핀셋 | `tweezers` | 작업대 위 브래킷 | 네일 파츠 중앙 홈을 집는다. 그리퍼 파지 폭을 코드와 동일하게 맞춰야 함 |
| 네일 파츠 트레이 | `stone_tray` | **높이 받침 블록** 위 투명 접시를 고정 | 접시를 고정하지 않으면 파츠를 집을 때 접시가 따라 올라옴 |
| 파츠 압착점 | `stone_place` | 네일팁 위 부착 지점 | 접근 → 압착 구간만 이동 속도 1/5로 저속화 |
| **인조 네일팁 (작업물)** | `nail_local_frame` | 실리콘 손가락 모형 + 지그로 높이 확보 | 손톱 경계는 측정값이 아니라 티칭한 타원 **16 × 13 mm** |
| 랙 진입 경유점 | `rack_transit` | 공중에 뜬 지점 — 셀에서 가장 높음 | 파일·젤 네일·핀셋만 경유. 계산으로 만든 경유점은 특이점 위험이 있어 직접 티칭 |
| 툴 랙 기준 프레임 | `tool_rack_frame` | 랙 전체의 기준 위치 | 실측했으나 **현재 사용처 없음** — 슬롯을 개별 티칭하는 방식으로 전환 |

## 4. 작업 환경 · 치구

### 작업대 — 베이스플레이트 + 랩
- 베이스플레이트가 작업대 전체의 기준면
- 표면에 랩을 씌워 젤·분진 오염 방지 — 오염되면 랩만 교체
- 매트 위에 놓고 테이블에 고정

### 툴 랙 5슬롯
- 슬롯마다 형태가 달라 툴이 항상 같은 자세로 놓임
- 파일·젤 네일·UV·핀셋 네 자리는 작업대 위
- 붓만 **작업대 바깥 구멍**에 수직으로 꽂아 세워 보관

### 작업물 지그
- 실리콘 손가락 모형을 지그로 툴 랙보다 높게 들어 올림
- 모형 위에 인조 네일팁을 부착하고 그 팁에 시술
- 손톱 경계는 센서가 아니라 티칭한 타원값

### 높이 받침 (높이 받침 블록)
- 투명 접시(네일 파츠 트레이)를 로봇이 집기 좋은 높이로 올리는 받침
- 접시를 고정 — 파츠를 집을 때 접시가 따라 올라오지 않게

### 계획했으나 없는 장비
- F/T 힘·토크 센서 — 장착돼 있으나 **미작동**, 전 공정 미사용
- 손 안착(handrest) 감지 센서 — 미장착
- 더스트 컬렉터 — 미장착
- 비전 카메라 — 미도입

### 안전 장치
- E-Stop은 **티치펜던트 내장 버튼** — 별도 비상정지 박스 없음
- 소프트웨어 감시는 `robot_state` 기반 E-Stop·통신두절 2종
- UV는 상시 ON이라 소프트웨어가 아닌 **취급 주의**로만 관리

## 5. 확인이 필요한 사항

도면을 그리며 발견한 것 — 스톤을 붙이는 `stone_place` 지점이 손톱 프레임
원점(`nail_local_frame`)에서 XY로 약 **62mm** 떨어져 있다. 스톤을 손톱 중앙에
붙이는 것이라면 두 좌표는 거의 같아야 한다. 손가락 모형에 네일팁이 여러 개 붙어
있어 서로 다른 팁에 티칭한 것이라면 정상이고, 같은 팁을 노린 것이라면 둘 중 하나가
어긋난 상태다.
