# 웹 시스템 개발 요구사항 정의서

**문서 ID** WRD-NAIL-v1.0 · **작성일** 2026-08-21
**대상** 네일 셀 웹 시스템 (FastAPI + React) · **기간** 3일 · **담당** 주은
**관련** SDS-NAIL-v1.0 (개발명세서) · IDS-NAIL-v1.0 (인터페이스 정의서)

**갱신 2026-08-24**: probe(강성 히트맵)·검증(3점 판정)·접촉력 그래프
시각화를 웹 범위에서 제거하기로 결정. 관련 FR/IR/DR/NFR 항목을 이
문서에서 함께 제거함 (ROS2 쪽 `nail_msgs`/`session_orchestrator`는
변경 없음 — 이 결정은 웹 시각화·저장 범위에만 적용됨).

---

## 1. 개요

### 1.1 목적

ROS2 기반 네일 셀의 공정을 웹에서 시작·감시·기록하는 시스템을 구축한다.

### 1.2 시스템 구성

```
React ──WebSocket/REST──▶ FastAPI + rclpy (단일 프로세스) ──DDS──▶ ROS2
                                  └──▶ SQLite
```

**FastAPI 는 `rclpy` 노드와 같은 프로세스에서 동작한다.** 별도 브리지(rosbridge)를 두지 않는다.

### 1.3 역할 경계

| 구성요소 | 책임 | 하지 않는 것 |
|---|---|---|
| React | 표시, 입력 | 판단 |
| FastAPI | 중계, 저장 | **공정 판단·재시도 결정·안전 판정** |
| ROS2 | 공정 실행, 판정 | — |

> **웹은 관측자다.** 공정 판단은 전적으로 `session_orchestrator` 가 소유한다. 웹에서 저수준 로봇 명령을 노출하지 않는다.

---

## 2. 범위

### 2.1 포함

세션 시작·취소 / 실시간 공정 감시 / 안전 상태 표시 / 결과 저장

### 2.2 제외

| 항목 | 대체 |
|---|---|
| 이력 조회 화면 | SQLite 직접 조회 |
| probe(강성 히트맵) · 검증(3점 판정) · 접촉력 그래프 표시·저장 | 웹 범위에서 제거(2026-08-24) — ROS2 쪽 판정/스캔 로직 자체는 그대로 동작 |
| 레시피 CRUD | `recipes.yaml` |
| 로그인·권한 | 단일 운영자 가정 |
| PDF 리포트 · 다국어 · 모바일 | 없음 |

## 3. 기능 요구사항

우선순위 **M**(필수) / **S**(권장)

### 3.1 세션 관리

| ID | 요구사항 | 우선 | 인수 기준 |
|---|---|---|---|
| FR-01 | `recipes.yaml` 의 레시피 목록을 조회할 수 있다 | M | 목록이 화면 선택지로 노출 |
| FR-02 | 레시피·형상·레이어 수를 선택해 세션을 생성한다 | M | 세션 레코드 생성 + `RunSession` goal 전송 |
| FR-03 | `target_material` 이 허용 목록(`silicone_model`, `artificial_tip`)이 아니면 거부한다 | M | 미허용 값 요청 시 400 |
| FR-04 | 세션이 이미 실행 중이면 신규 요청을 거부한다 | M | 중복 요청 시 409 |
| FR-05 | 진행 중 세션을 취소할 수 있다 | M | 액션 cancel 이 ROS2 까지 전파 |
| FR-06 | orchestrator 액션 서버가 없으면 시작을 거부한다 | M | 3초 대기 후 503 |

| ID | 요구사항 | 우선 | 인수 기준 |
|---|---|---|---|

> 이상 그 결과를 구독·표시하지 않는다.

### 3.3 판정 결과

> **제거됨(2026-08-24)**: 이전 FR-20~23(3점 판정 레이어별 표시, 임계값
> 노출, 리포트 문구 제약, 재작업 횟수 표시)은 검증 단계 시각화 제거로
> 삭제됨. 판정 로직 자체는 ROS2 쪽에서 그대로 수행되며, 웹은 더 이상 그
> 결과를 구독·표시·저장하지 않는다.

## 4. 인터페이스 요구사항

### 4.1 ROS2 구독

| 토픽 | 타입 | QoS | 용도 |
|---|---|---|---|
| `/safety/status` | `SafetyState` | **TRANSIENT_LOCAL** | 안전 배너 |
| `/process/status` | `ProcessState` | **TRANSIENT_LOCAL** | 진행 표시 |

**제거됨(2026-08-24)**: `/stiffness/map`(히트맵)·`/validation/result`(판정)·
`/force/data_ui`(힘 그래프) 구독은 probe/검증 단계 시각화 제거로 뺐다.
(참고: 토픽 자체는 `nail_bridge` 화이트리스트에는 남아 있을 수 있으나
웹 백엔드가 더 이상 구독하지 않는다.)

**요구사항**
- IR-01 (M): 래치 토픽 2종은 TRANSIENT_LOCAL QoS 로 구독한다. 미준수 시 늦게 기동한 웹이 현재 상태를 받지 못한다.

### 4.2 ROS2 액션

| 액션 | 타입 | 용도 |
|---|---|---|
| `/session/run` | `RunSession` | 세션 실행·취소·피드백 |

- IR-03 (M): goal 전송, 취소, feedback 수신, result 수신을 모두 지원한다.
- IR-04 (M): 액션 서버 미기동 시 3초 타임아웃 후 오류를 반환한다.

### 4.3 WebSocket (서버 → 클라이언트)

**단일 채널 `/ws`, `type` 필드로 분기한다.**

| type | 내용 | 빈도 |
|---|---|---|
| `safety` | 안전 상태 | 변경 시 |
| `state` | 공정 상태 | 전이 + 1 Hz |
| `error` | 에러 코드 + 심각도 | 이벤트 |
| `result` | 세션 종료 결과 | 1회 |

**제거됨(2026-08-24)**: `map`(강성 맵)·`verdict`(3점 판정)·`force`(접촉력
샘플) 타입은 probe/검증 단계 시각화 제거로 뺐다.

```json
{"type":"safety","data":{"safe_to_move":false,"active_faults":["FAULT_ESTOP"]}}
```

- IR-05 (M): 클라이언트 접속 시 서버는 최신 `safety` / `state` 를 즉시 전송한다(스냅샷). 새로고침 후 화면이 비어 있어서는 안 된다.
- IR-06 (M): 연결이 끊기면 클라이언트는 2초 간격으로 자동 재연결한다.
- IR-07 (M): **웹 연결이 끊겨도 ROS2 세션은 계속 진행된다.** 웹 종료가 로봇을 중단시키지 않는다.

### 4.4 REST

| Method | Path | 설명 |
|---|---|---|
| GET | `/api/recipes` | 레시피 목록 |
| POST | `/api/sessions` | 세션 생성 + 시작 |
| POST | `/api/sessions/{id}/cancel` | 취소 |
| GET | `/api/sessions/{id}/report` | 세션 기본 정보 조회 (probe/검증 결과 필드는 2026-08-24 제거됨) |
| GET | `/api/health` | 상태 확인 |

## 5. 데이터 요구사항

원문은 SQLite(`nail.db`) 1개를 전제했으나, 팀 결정으로 **Postgres**를
쓴다(`web/backend/app/persistence.py` 주석 참고).

| 테이블 | 주요 컬럼 |
|---|---|
| `sessions` | id, recipe_id, target_material, started_at, finished_at, result_code, abort_reason |
| `events` | session_id, ts, mtype, detail |

**제거됨(2026-08-24)**: `stiffness_maps`(강성 맵)·`verdicts`(3점 판정,
`threshold_n`/`waveform` 포함) 테이블은 probe/검증 단계 시각화 제거와
함께 삭제됨. 이전 DR-01(`verdicts.waveform` FAIL 시 필수)·DR-02
(`verdicts.threshold_n` 저장)도 해당 테이블과 함께 삭제됨.

- DR-03 (M): 20 Hz 힘 데이터는 저장하지 않는다(용량).
- DR-04 (S): 모든 이벤트에 `session_id` 와 타임스탬프를 부여한다.

## 9. 인수 기준

아래를 모두 충족하면 완료로 판정한다.

1. 가짜 퍼블리셔로 세션 시작 → 공정 진행 표시 → 저장 확인

3. 브라우저 강제 종료 후 재접속 시 현재 상태 즉시 복원
4. 세션 취소가 ROS2 액션까지 전파
5. 웹 종료 시에도 ROS2 세션이 정상 진행
6. **M** 등급 요구사항 전 항목 충족

**제거됨(2026-08-24)**: 히트맵 렌더링·판정 표시·저장 확인(구 1번 일부),
FAIL 파형·임계값 DB 확인(구 6번), FR-22 리포트 문구 준수(구 7번), 30분
메모리 누수 확인(구 8번, `ForceGraph` 대상)은 관련 기능 삭제로 함께
